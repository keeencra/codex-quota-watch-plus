# Mac 显示模块来源

本目录整合所有者维护的 Codex Usage Bar 当前本地实现：v0.11.0 正式基础，以及尚未单独发布的 v0.12.0 菜单栏紧凑布局、macOS WidgetKit 小／中／大号组件和重置券明细。原项目位于同一所有者的独立工程，本次整合不删除、覆盖或重新发布它的历史版本。

原始代码的 MIT 许可及版权保留在本目录 LICENSE。码伴仓库整体继续使用根目录 AGPL-3.0；不得移除原始 MIT 声明。早期界面理念参考 QuotaDot、codex-float 和 TokenRemain，未引入其商标或截图。

本目录后续按码伴统一发布规范维护，不沿用原项目的独立版本计数。docs/assets 中 v0.11.0／v0.12.0 图片来自本模块原生视图离屏渲染，使用虚构数据，版本名标明采集时的来源阶段。
