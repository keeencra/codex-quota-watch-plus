# iOS 26／27 兼容说明

v3.3.2 保留同一套手机、手表和小组件源码，支持 iOS 26 与 iOS 27；无需为两个系统分别下载项目。

## 系统与开发工具

| 项目 | 配置与要求 |
| --- | --- |
| iPhone App／小组件最低部署版本 | iOS 17.0，未提高到 27；包括 iOS 26／27 |
| Apple Watch 最低部署版本 | watchOS 10.0，保留 watchOS 26／27 的运行范围 |
| 连接 iOS／watchOS 27 真机 | 使用 Xcode 27 并完成首次启动的系统组件安装；保持设备开发者模式、信任和连接 |
| Xcode 27 的 Mac 系统要求 | macOS 26.6 或更高版本，以 [Apple 官方支持表](https://developer.apple.com/xcode/system-requirements) 为准 |

SDK 是编译工具版本，最低部署版本决定应用允许运行的系统范围。使用 Xcode 27 构建不等于要求手机升级到 iOS 27。分区列表使用已有 SwiftUI List／Section 和 Foundation 解码，没有引入仅限 iOS 27 的 API。

## v3.3.2 实际验证

| 环境 | 结果与边界 |
| --- | --- |
| Xcode 26.6 | 同批修复的手机／手表签名构建通过 |
| Xcode 27.0 | 公开工程的手机、手表、小组件设备构建与模拟器构建通过；构建不等同于实机验收 |
| iOS 26.5 模拟器 | 安装并启动 Xcode 27 构建的原生任务演示宿主，检查分区／项目／任务层级；数据虚构，不执行网络请求或审批 |
| iOS 27.0／watchOS 27.0 真机 | 同批修复包已安装成功，用户确认分区显示。安装包来自此前 Xcode 26.6 签名构建，手表通过 Xcode 27 工具完成安装；没有声称重装了最新 SDK 构建包 |
| 回归测试 | 169 项 Python、76 项共享 Swift 测试通过；覆盖分区排序、混合任务、项目 ID 迁移、账户选择、重复项、空项目与旧数据兼容 |

尚未逐项验证所有系统小版本、全部系统外观和所有功能的真机组合。iOS 26 的本次验证为模拟器，iOS／watchOS 27 为用户现有设备确认。

Xcode 27 下运行 Swift 测试时，云同步工作区的附加属性可能导致测试包签名失败。使用本地构建缓存可避免该环境问题：

```bash
swift test --package-path ios-watch --scratch-path /tmp/codecompanion-swift-tests
```

## 升级系统后无法安装

若报「开发者磁盘映像无法挂载」，先更新 Xcode 并完成系统组件安装，再保持设备解锁和可连接状态重试。本次 watchOS 27 安装在工具更新后恢复。若安装已成功但远程启动连接超时，不能据此判断应用崩溃；可直接在设备打开应用确认。

iOS／watchOS 模拟器下载只用于在 Mac 测试界面，不是已安装手机／手表应用运行的前提。日常同步需要 Mac 服务在线，但无需保持数据线连接。
