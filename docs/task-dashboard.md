# 任务总览

手表打开后首先显示运行中任务、实时待审批和剩余额度。点卡片进入任务列表、逐项审批或额度详情；左右滑动仍可查看完整额度和今日用量。手机首页使用相同层级，连接、通知和诊断设置可展开查看。

任务页可切换“进行中与待处理”和“全部任务”。详情显示本地 Codex 任务标题（不可用时显示项目名）、当前阶段、运行状态和最近五次阶段变化。阶段根据实际事件归类为开始处理、分析、执行工具、收到工具结果、整理回复等，不计算或猜测完成百分比。

## 数据及刷新

- `/tasks` 是网关提供的独立认证接口，要求 HTTPS 入口与有效的 `x-watch-token`。旧版 `/watch` 及小组件数据结构不变。
- 任务数来自已跟踪的任务事件，同一会话取最新一轮，不依赖 `/watch` 最近十条记录。首次启用观察器不会回放历史，因此它不代表电脑上所有未被跟踪的任务。
- 前台每十秒读取任务和审批，网络失败时数量显示“—”，旧任务详情带提示。长时间没有活动的任务标记状态待确认，不继续算作实时运行数。
- 待审批数只计算审批接口中仍可操作的实时请求；等待用户文字回复、历史审批提示不计入该数量。
- 任务阶段需升级 Mac Python 包并重启通知进程和网关；旧记录没有标题或活动明细时降级显示项目名和状态。

## 隐私与授权

任务标题只从 Mac 的本地 Codex 状态数据库只读获取，经认证接口送到自己的 App；手机／手表只在内存中保存该详情，不加入额度缓存、WatchConnectivity 快照、小组件或 Bark 通知。阶段与事件使用固定描述，不读取或转发命令参数、提示词、工具输出和助手原文。

远程审批仍需打开完整操作，确认后批准本次或拒绝。本次界面改版不改变审批能力及边界，具体支持范围见 [远程审批](remote-approval.md)。
